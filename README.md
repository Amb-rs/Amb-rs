### Who am I?
I'm one of the top contributors for [LostCityRS](https://github.com/LostCityRS), completely open-source game aiming to recreate and **preserve** the lost versions of the MMORPG RuneScape. This requires reverse engineering the RuneScape engine, sifting through thousands of old RuneScape videos of the era, and scraping website archives of RuneScape media and fansites. Our motto is authenticity over all. What matters is the server code and how accurate it is to the era. We DO NOT sacrifice authenticity over quality of life! Such additions should be up to server owners who fork this project.


Lost City has took the liberty to run it's own servers, using the recreated and preserved code. You can register an account an play at https://2004.lostcity.rs/. It's completely free and requires no download!

### How far has Lost City gone?
We plan to recreate several versions from 2004 to 2006. For a detailed analysis for how we choose the version dates, read our [roadmap](https://2004.lostcity.rs/news/215). So far we have released two, feature complete, versions of the game:
- May 18, 2004
- June 28, 2004

In terms of historical accuracy, the level of detail we have gone through is unprecidented. Every nook and cranny of this game is meticulously thought out. For example, we recreated RuneScape's proprietary scripting language RuneScript. This helps us piece together design decisions and mechanical limitations that help make old RuneScape so great. We've even gone as far as matching typo's and game breaking bugs - Remember, authenticity over everything!
