# Hi, I'm Amber

Software developer focused on TypeScript and games. I'm a top contributor to
[Lost City](https://github.com/LostCityRS), an open-source recreation of RuneScape 2.

## What I build at Lost City
I write gameplay logic in RuneScript, RuneScape's custom scripting language, and fix the TypeScript engine
underneath when content needs it. The project's rule is accuracy over convenience, so I
reproduce original behavior, including historical bugs.

- **Combat and PvP:** combat interactions, special attacks, prayer, magic, cannons
- **Skills:** smithing, crafting, cooking, woodcutting, firemaking, fishing, fletching
- **Quests and minigames:** Dragon Slayer, Duel Arena, Fishing Trawler, Mage Arena
